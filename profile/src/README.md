# 프로필 그림 원본

`profile/assets/` 의 PNG 는 이 HTML 을 찍은 것이다. 글자를 바꿀 때는 여기를 고치고 다시 찍는다.

| 그림 | 원본 | 크기(CSS px) |
|---|---|---|
| 배너 | `banner-light.html` · `banner-dark.html` | 1280 × 460 |
| 경보 하나의 일생 | `flow-light.html` · `flow-dark.html` | 1280 × 400 |
| 만드는 원칙 | `principles-light.html` · `principles-dark.html` | 1280 × 510 |

- Chrome 에서 열고 개발자 도구의 기기 모드로 위 크기, 배율 2 로 「스크린샷 캡처」 — 2배 PNG 가 나온다.
- 글꼴은 Pretendard(SIL OFL 1.1)를 CDN 에서 불러온다. 다 불러온 뒤 찍는다.
- 색은 브랜드 그대로다 — 남색 `#142846`, 안전 노랑 `#FFCF4B`. 노랑을 흰 바탕에 직접 놓지 않는다(밝은 판의 작은 글씨는 남색 계열).
- 로고 경로는 Brand 저장소의 SVG 원본을 옮겨 넣은 것이다.
